# Probability Theory

This repository contains the LaTeX source files for the **Probability Theory** course notes.

The source files are organized as follows:

- `Probability Theory.tex`: the main LaTeX document, including the document settings and chapter entries.
- `Chapters/`: the source files for individual chapters.

The repository will be updated as new notes or corrections become available.

Compiled PDFs will be published through [GitHub Releases](https://github.com/westlake-noter/Probability-Theory/releases). Please visit the Releases page for downloadable versions of the notes. The source tree is used to maintain the LaTeX files.

## Contributing

Typo fixes, mathematical corrections, and improvements to explanations or typesetting are welcome. If you notice an issue, please open an issue or submit a pull request with a focused change. When reporting an error, please indicate the relevant chapter, section, or statement so that it can be located easily.

# 概率论

本仓库用于整理和维护 **概率论** 课程笔记的 LaTeX 源文件。

源文件按以下结构组织：

- `Probability Theory.tex`：LaTeX 主文件，包含文档设置及各章节的引入。
- `Chapters/`：各章节的 LaTeX 源文件。

仓库将随新增笔记的整理及勘误持续更新。

编译后的 PDF 将通过 [GitHub Releases](https://github.com/westlake-noter/Probability-Theory/releases) 发布。请前往 Releases 页面下载相应版本的笔记；源代码目录用于维护 LaTeX 文件。

## 贡献

欢迎提交文字勘误、数学内容修正，以及表述和排版方面的改进。如果发现问题，可以提交 issue，或提交一个聚焦具体修改的 pull request。报告错误时，请注明相关章节、小节或具体结论，以便定位。
